# Shape an original-question retrieval baseline

Labels: enhancement, needs-info
Parent: [Chat Session error follow-up](../MAP.md)

## Outcome

Preserve the original question as the assessment and retrieval input, reducing
the chance of losing publication-date scope, bounded results, chronological
order, or the requested task. Shape the smallest production change once routing
and approval behavior are settled. A RAG comparison can measure rewriting's value
without making rewriting mandatory in production.

- Existing Graph-Prioritized Retrieval and Local Retrieval Chat contracts require

## Boundaries

This record does not choose a routing architecture, remove approval by inference,
add a generic intent language, tune passage ranking, or improve the old rewrite
prompt. Voter editing for unresolved referents is part of the Source Guide design;
a general automatic clarification/reformulation workflow is not a prerequisite.
