## Guardrails for follow-up work

Evaluation Data Sets and reports use the existing Git-backed runtime in
[ADR 0017](../../../docs/adr/0017-git-is-the-evaluation-versioning-system.md).
Human-reviewed labels are Gold; model-authored labels remain Silver and pending
examples stay unlabeled. Keep reviewed training examples separate from held-out
checks and report outcomes by failure type before selecting quality floors.

Prompt changes follow
[ADR 0022](../../../docs/adr/0022-prompts-are-immutable-versioned-text-resources.md).
Add a new explicit version; preserve old prompt bytes and historical reports.
Clarification before every search, a new answering agent, a generic intent
language, and a repository-wide retry redesign are not requirements of this queue.
