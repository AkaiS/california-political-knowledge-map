## Agent Brief

**Category:** bug
**Summary:** Give question assessment and final guidance the same explicit,
reproducible date context.

**Current behavior:**
Model-facing preparation has no explicit current date. Historical questions can
be judged against an assumed date even though telemetry knows when the session
started.

**Desired behavior:**
A Chat Session resolves one as-of timestamp in UTC at creation and provides its
calendar date explicitly to question assessment and final guidance. The same
value remains stable through corrections, approval, and answering. Evaluation
can supply a fixed timestamp to reproduce historical cases. The timestamp is
recorded with the session and relevant evaluation inputs.

**Key interfaces:**
- `ChatSession` request context and model-facing assessment/guidance inputs.
- Chat evaluation case/run inputs, using the existing Data Set and report runtime.
- Explicitly versioned prompt resources if instructions must change.

**Acceptance criteria:**
- [x] Both assessment and guidance expose the resolved date as input data.
- [x] A test fixes the date at 2026-10-01 and verifies September 2026 questions
      receive that context. It does not claim scripted output proves model quality.
- [x] One session crossing midnight retains its original as-of value.
- [x] Repeated evaluation with a supplied date renders the same date context.
- [x] Trace and report provenance permit recovering the effective as-of value.
- [x] Publication dates remain distinguishable from event dates and session time.
- [x] Any changed instruction selects a new immutable prompt version.

**Out of scope:**
- General natural-language date parsing or event-time database reconstruction.
- Changing coverage definitions, retrieval ranking, or the Query Rewriter workflow.
- A new evaluation persistence mechanism.

## Triage recommendation

`ready-for-agent`: the missing input is reproduced and the behavior above is
bounded. UTC is the existing session-observation convention, not a promise to
interpret the user's local timezone. Promotion awaits maintainer direction.
