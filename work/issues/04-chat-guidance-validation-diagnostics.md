## Agent Brief

**Category:** bug
**Summary:** Make invalid source guidance diagnosable from the application trace.

**Current behavior:**
Guidance can fail because it names an unselected source or a disagreement lacks
distinct selected sources. The application failure record identifies validation
but drops the specific violated rule. The user-facing failure remains generic.

**Desired behavior:**
Keep a stable, actionable application diagnostic for known guidance validation
rules. Include a rule identifier, field location when available, and bounded
source identifiers relevant to that rule. Preserve the existing user-facing
failure handling, selected-source validation, and retained retrieval evidence.

**Key interfaces:**
- `RetrievalAnswer` selected-source guidance validation.
- `SourceRelevanceNote`, `SourceDisagreement`, and `ChatSession` guidance failure
  observations.
- Existing Logfire telemetry scrubbing and attribute conventions.

**Acceptance criteria:**
- [ ] Duplicate disagreement source IDs identify the distinct-selected-sources
      rule and the disagreement field or item location.
- [ ] An unselected source note identifies the selected-source rule and offending
      source identifier when safe under the existing telemetry policy.
- [ ] Unselected disagreement IDs remain distinguishable from repeated IDs.
- [ ] Where a model/library error exposes no structured field location, record
      that limitation without inventing a constraint or dumping provider output.
- [ ] Diagnostics retain the Chat Session association and validation failure kind.
- [ ] Application attributes remain bounded and scrubbed; no raw provider body,
      credentials, or arbitrary exception text is introduced.
- [ ] The retrieval package remains inspectable and no answer is marked prepared
      after validation failure.
- [ ] Existing transport/provider/unexpected failure handling remains intact.

**Out of scope:**
- Relaxing validation, automatic guidance repair, or changing retry policy.
- Duplicating model-request telemetry or replacing Logfire.
- UI redesign or live model evaluation.
