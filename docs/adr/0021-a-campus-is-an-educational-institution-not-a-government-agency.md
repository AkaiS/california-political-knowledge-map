# A campus is an Educational Institution, not a Government Agency

`:Organization` gains an `:EducationalInstitution` sub-label, in `ontology.md` and in the primary ontology module that mirrors it. Colleges, universities and university systems carry it. The public-vs-private split that previously decided between `:GovernmentAgency` and no sub-label at all is gone.

This is a correction to `ontology.md` and so it engages the bar in [ADR 0014](0014-the-primary-ontology-is-authored-not-frozen.md). What clears the bar is that the sub-label vocabulary forced a wrong assertion and offered no way to decline it. The eleven sub-labels named a kind of organization by what it *is* — a corporation, a union, a trade association, a tribal nation, a news outlet — and a university is a kind of organization on exactly that footing. It was missing, so a campus had two landing places and both are wrong. `:GovernmentAgency` asserts that UC Berkeley administers state authority, which no passage that names it says and which is false about the thing itself: a public university is a public body, but "agency" is not the kind of body it is, and the graph cannot tell it apart from the Department of Corrections. Bare `:Organization` asserts nothing, so Cornell and UC Davis — the same kind of institution, named the same way in the same corpus — sorted into different shapes of node on a distinction the prose never drew. That is a taxonomy whose only available answers are both untrue, which is the same defect as a property declared on the wrong entity: the model is made to say something the source does not support. It is not a naming preference, and it is not an inconvenient shape.

The News Ontology could not work around it. A Divergence records a property news cannot supply and a Shortcut Rule records a path news flattens; neither can add a member to a closed vocabulary, and a sub-label the primary ontology does not declare is one conformance drops. There was no workaround to reach for before reaching for the document, which is the order ADR 0014 asks for.

The gap was visible in the extraction evaluation before it was named here. Eleven campus nodes were the largest single group of systematic misses across five runs — missed in every run, not drawn against — and the prompt is rendered from the same closed vocabulary, so it told the model to attach a sub-label only where the passage supports it and then offered nothing a passage about a university supports. The model declined, correctly. Silver had the same problem from the other side and resolved it by fiat, putting California campuses under `:GovernmentAgency` and out-of-state ones under bare `:Organization`.

## Considered options

Ruling that campuses are `:GovernmentAgency` and saying so in the prompt is the cheapest change: no ontology edit, no ADR, and the rule is teachable in one line. It is rejected because it makes the graph assert something false and then teaches the model to assert it too. It also leaves the public-vs-private line in place, and that line is not in the text — an annotator or a model reading "Cornell University" has to know the answer from elsewhere, which is exactly what annotation guidance forbids.

Leaving the vocabulary alone and letting campuses carry no sub-label keeps the ontology untouched and is honest about what a passage states. It is rejected because it throws away a distinction the passage *does* state. "Sacramento State University professor Kimberly Nalder" says what kind of organization that is; a bare `:Organization` records that a name was seen and nothing else, and the same query that wants every university has to enumerate them.

Splitting the sub-label into public and private variants preserves the older distinction. It is rejected for the reason the older distinction failed: a chunk names a campus far more often than it says who funds one, so the finer vocabulary would be unanswerable from the text in most cases, and an unanswerable sub-label is one the extractor is right to omit.

## Consequences

`:EducationalInstitution` reaches the extraction prompt without further work, because the prompt's sub-label block is rendered from `news.SUB_LABELS`. Sub-labels on `:Organization` stay optional and multiple, so nothing forbids a campus that a passage really does describe as an administering agency from carrying both; nothing in the corpus currently does.

Twelve nodes in the extraction silver set were relabelled to match, and the annotation guidance was rewritten to name the new rule and retire the public-vs-private one. That edit moves the extraction metrics on its own, independently of any change in model behaviour — the trap [ADR 0017](0017-git-is-the-evaluation-versioning-system.md) exists to make visible, since the silver edit and the ontology edit land in the same commit and a run either side of it is not comparing the same thing twice.

`Cal State Board of Trustees` carries the sub-label as well. A governing board is not itself a campus, and a strict reading would leave it bare or send it back to `:GovernmentAgency`. Neither is better: the chunk names the board only as the body that governs the CSU system, so `:EducationalInstitution` is the most the passage supports and any sharper answer is knowledge from elsewhere. If governing bodies turn out to need separating from the institutions they govern, that is a further sub-label and a further decision, not a reason to hold this one up.

The `:AdvocacyGroup`-versus-`:NonProfit` overlap is untouched and still has no discriminator. It is a different defect — two sub-labels that both fit, rather than none that fits — and it wants its own decision.
