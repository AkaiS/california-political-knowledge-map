# Bind Evaluation Gold Sets to one task contract

An Evaluation Gold Set version binds one exact Evaluation Task Contract and contains only exact Evaluation Case revisions matching its input, expected-output, and metadata schemas. This keeps the full Gold Set coherent, executable, and aggregatable for one component operation; subset selection may vary splits, tags, and Evaluation Requirement coverage, but cannot conceal task-schema incompatibility. Cases for different component operations belong to distinct Gold Sets even when they share source artifacts or provenance, while legitimate shape variation is modeled explicitly inside the shared schemas.
